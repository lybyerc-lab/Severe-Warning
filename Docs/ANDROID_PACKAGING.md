# Android Packaging Handoff

Last updated: 2026-07-31

## Current state

The repository contains a Capacitor `8.5.0` Android project for Severe Weather v3.2.0. The web bundle and Android asset sync have passed, but no APK has been compiled on this work PC because company policy does not permit installing Android Studio, the Android SDK, or a JDK.

Do not treat the presence of `android/` as proof that the app builds or runs on a phone.

## Permitted build-machine requirements

- Node.js 22 or newer
- Android Studio with Android SDK 36
- JDK 21 (the Java level generated by Capacitor 8.5.0)
- Git
- an Android device with developer-mode USB debugging, or an Android emulator

The application ID is currently `com.lybyerclab.severeweather`. Changing it after public distribution creates a different Android application identity, so confirm it before the first signed release.

## Reproduce the web bundle

From the repository root:

```powershell
pnpm install --frozen-lockfile
npm run build
npm run cap:sync
```

`scripts/build-web.mjs` creates the ignored `www/` directory from `MechanicsLab/SevereWeather_3D_Lab.html`, copies only local font resources, rejects external script or stylesheet URLs, and writes build provenance to `www/build-info.json`.

## Compile a debug APK

Either open `android/` in Android Studio and build the debug variant, or run:

```powershell
npm run android:debug
```

Expected APK location:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Capacitor sync may update generated files under `android/app/src/main/assets/`. Review the Git diff before committing any native-project change.

## Device acceptance checklist

- app opens directly in landscape and stays fullscreen
- Tornado, Supercell, and Derecho controls accept simultaneous joystick and ability touches
- a full three-minute run sustains acceptable frame pacing without excessive heat or battery drain
- backgrounding pauses the run; returning does not jump the timer or storm simulation
- audio behaves after first interaction, interruption, backgrounding, and return
- Android Back backgrounds the game instead of discarding the run
- Neon Funnel unlock survives force-close and reopen
- the entire run works with airplane mode enabled
- no crew or animal can be destroyed or counted as a target
- retry rebuilds one clean world and remains responsive

Record the phone model, Android version, WebView version, APK commit, test duration, approximate FPS, heat, battery delta, and every observed defect in `Docs/DEVICE_TEST_LOG.md`.

## Release boundary

Before a public build, replace the generated Capacitor launcher icon and splash art, set production logging policy, confirm the application ID, create a private signing key on the release machine, and document a recoverable signing-key backup. Never commit a keystore or signing credentials.
