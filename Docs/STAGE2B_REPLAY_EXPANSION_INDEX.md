# Stage 2B Replay Expansion Index

Canonical companion: `Docs/LEVEL_AND_RPG_EXPANSION.md`

This short index exists so future workers and Directors can find the level/progression direction quickly.

## Locked product direction

- **Severe Weather Warning** is a mobile arcade destruction game with light action RPG progression.
- The current four levels are a starting set, not the intended final content count.
- New destruction sites should be addable through a bounded, data-driven site/level package rather than repeated campaign-core surgery.
- Replays of the same site may vary through authored objective/prop/event/secret pools while preserving recognizable place identity.
- Established site families include county fair/fairground, pier/boardwalk, beach/coast, mall/open-air shopping district, strip mall/roadside retail, stadium/event grounds, and grocery-store variants.
- Memorable feats can unlock storm skins/forms, including a coastal boat-launch feat for a Waterspout skin/form.
- Working soft-currency name: **MOO-LAH**. Coin/token identity uses a cow/Cow 17 face motif on one side and an udder emblem on the other.
- MOO-LAH is earned through play by default, not a real-money economy.
- Pull, Gust, Grid Zap, and future storm-core utility can receive bounded persistent upgrades.
- Core abilities must remain fun at base level; upgrades deepen play rather than create grind or invalidate skill.
- The Weather Map should evolve into a growing destination board containing campaign anchors, destruction playgrounds, secret levels, score attacks, and teased locked sites.
